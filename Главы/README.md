# «Фон эпоса», текст по главам

Здесь хранится побуквенная копия действующей рукописи, разбитая на **26 отдельных TXT-файлов**.

- Источник: `Книга про всякое, попытка 90123... (2).txt` (ветка `main`).
- Коммит источника: `d7b8e350ca2e9e7bac304a3aab5c190c070695be`.
- Git blob исходного TXT: `dff400a477a50917598a97b2395ad7806ca7402a`.
- Главы названы `Глава_01.txt` … `Глава_26.txt` для правильной сортировки.
- Содержимое глав не редактировалось. Каждый файл начинается с собственного заголовка «Глава N».
- Исходное вступление вне глав: название книги `Фон эпоса`, после него две последовательные перевода строки (LF).
- Для точного восстановления оригинала требуется добавить строку `Фон эпоса\n\n` перед последовательной конкатенацией файлов от 01 до 26.

Канонический полный TXT и FB2 остаются в корне репозитория, эта папка представляет дополнительную удобную поглавную копию. При дальнейшей литературной редактуре необходимо обновлять поглавную копию синхронно с основным TXT/FB2.
